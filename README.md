## Plan of Action

The project focuses on the teleoperation of a Kinova robot in simulation. An Inertial Measurement Unit (IMU), consisting of an accelerometer and gyroscope, will control the end-effector's pose through scaled Cartesian movements to achieve fine precision. A dead man's switch, utilizing an IR sensor to detect the operator's finger, will be implemented for safety and control. A rotary encoder will manage the gripper's opening and closing actions as well as joint state manipulation.
